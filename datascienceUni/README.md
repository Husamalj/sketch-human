# Data Science – Project Phase 1 (Data Preprocessing)

## How to run in VS Code
1. Copy this `datascienceUni` folder to your Desktop.
2. Open the folder in VS Code (File > Open Folder).
3. Install the Python and Jupyter extensions, then run in the terminal:
   `pip install -r requirements.txt`
4. Open `Project_Phase1_Preprocessing.ipynb` and click **Run All**
   (or run `python project_phase1_preprocessing.py`).

## Contents
- `data/` – the original datasets (both files are identical)
- `Project_Phase1_Preprocessing.ipynb` – the main notebook (already run, outputs included)
- `project_phase1_preprocessing.py` – same code as a script (`# %%` cells)
- `outputs/` – cleaned / model-ready / train / test CSV files and `figures/`
- `report/Project_Phase1_Report.docx` – the report (fill in the team name and members)
- `Syllabus_Data_Science_F26.pdf`
